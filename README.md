# Python Logic Building

This repository contains my beginner-level Python logic-building practice as I develop my programming skills for Data Analytics.

## Topics Covered

* Variables and data types
* Conditional statements
* Loops
* Functions
* Arithmetic operations
* Number-based problems
* List traversal and comparisons
* Handling edge cases
